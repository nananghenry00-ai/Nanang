# Phone Location Tracker

## Introduction
This repository contains code for a Phone Location Tracker application, which allows users to track the location of their devices in real-time. It is designed to be user-friendly and efficient, making it ideal for personal use and small businesses.

## Features
- Real-time location tracking
- User-friendly interface
- Geofencing capabilities

## Prerequisites
Before you begin, ensure you have met the following requirements:
- Python 3.x installed
- Internet connection

## Setup Instructions
1. **Clone the repository**
   ```bash
   git clone https://github.com/nananghenry00-ai/Nanang.git
   cd Nanang
   ```

2. **Install required packages**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   python app.py
   ```

4. **Accessing the tracker**
   Navigate to `http://localhost:5000` in your web browser to access the phone location tracker.
